# Dummy (demo) ডেটা — ডাটাবেসে বসানোর দুই উপায়

সব ডেটা স্পষ্টভাবে **ডেমো** হিসেবে চিহ্নিত (নামে `Demo`/`[Demo]`, স্লাগে `demo-`)। আসল কনটেন্ট দেওয়ার আগে মুছে ফেলা যায়।

**কী কী আছে:** ৩টা নমুনা প্রজেক্ট (Upcoming/Ongoing/Completed, একটা Commercial), ৪টা লেখা (ব্লগ ২, নিউজ ১, ইভেন্ট ১ — একটা বাংলাসহ), ৬ জন টিম সদস্য, ৩টা চাকরি, A/B টেস্টসহ ১টা ক্যাম্পেইন পেজ, ২টা রিডাইরেক্ট, আর **৩০টা লিড** (গত ৩০ দিনে ছড়ানো, নানা ধরন/স্ট্যাটাস/সোর্স — ড্যাশবোর্ডে সংখ্যা ও চার্ট দেখাবে)। সাথে আসল ৭টা প্রজেক্ট ও সাইট সেটিংস।

---

## উপায় ১ (সুপারিশ): কমান্ড দিয়ে — যেকোনো ডাটাবেসে কাজ করে
`.env`-এ যে ডাটাবেস দেওয়া আছে (MySQL / PostgreSQL / SQLite) সেখানেই ঢোকে। টেবিলের কাঠামো নিজে মেনে চলে, তাই ভুলের সম্ভাবনা সবচেয়ে কম।
```powershell
npm run db:check     # টেবিল তৈরি হয়েছে কিনা দেখে
npm run seed         # আসল ৭টা প্রজেক্ট + সেটিংস + প্রথম admin
npm run seed:demo    # ডেমো কনটেন্ট + ৩০ লিড
```
আবার চালালে ডেমোগুলো নিজেই মুছে নতুন করে বসায় (দ্বিগুণ হয় না)। **ডেমো মুছতে:**
```powershell
npm run seed:demo -- --remove
```

## উপায় ২: phpMyAdmin → Import (`credence-demo-data.sql`)
ফাইল: `demo-data/credence-demo-data.sql` (MySQL/MariaDB-এর জন্য)।

1. আগে একবার `npm run db:check` চালাও — এতে টেবিলগুলো তৈরি হয় (খালি)।
2. phpMyAdmin → বাঁ পাশে তোমার ডাটাবেস (`credence_website`) → উপরে **Import** → **Choose file** → `credence-demo-data.sql` → নিচে **Import** (Character set `utf-8`)।
3. ইমপোর্টের পর অ্যাডমিন বানাও (ডাম্পে ইউজার/পাসওয়ার্ড নেই):
   ```powershell
   npm run create-admin
   ```
4. `npm run dev`।

⚠ ইমপোর্টের সময় ফাইলটা প্রতিটা কনটেন্ট টেবিল আগে খালি (`DELETE`) করে তারপর ঢোকায় — তাই এতে আগে বসানো কনটেন্ট মুছে যাবে। ইউজার টেবিল ছোঁয়া হয় না।

**আমি এই SQL ফাইল যেভাবে যাচাই করেছি:** (ক) MySQL গ্রামার দিয়ে ৪৫টা স্টেটমেন্ট সবই পার্স হয়েছে; (খ) সাইটের নিজের তৈরি খালি টেবিলে ইমপোর্ট করে ২০টা টেবিলের প্রতিটা সারি হুবহু মিলেছে (SQLite-এ)। **আসল MySQL/MariaDB সার্ভারে আমি চালাতে পারিনি** — ইমপোর্টে কোনো এরর এলে এরর লেখাটা পাঠাও, অথবা উপায় ১ ব্যবহার করো।

## ডাম্প নতুন করে বানাতে (ডেমো বদলালে)
```powershell
# .env এ DATABASE_URL=file:./credence.db রেখে
npm run seed ; npm run seed:demo ; npm run export:demo-sql
```
